MODULE CATALOG - DANH SÁCH API

🏷️ BRANDS (Thương hiệu)
1. Tạo thương hiệu mới
API: POST /api/v1/admin/brands
Chức năng: Tạo brand mới (Apple, Samsung...)

2. Danh sách thương hiệu
API: GET /api/v1/admin/brands
Chức năng: Lấy danh sách brands (filter, pagination)

3. Danh sách brands đã xóa
API: GET /api/v1/admin/brands/deleted
Chức năng: Lấy brands đã soft delete

4. Chi tiết thương hiệu
API: GET /api/v1/admin/brands/{id}
Chức năng: Xem chi tiết 1 brand

5. Cập nhật thương hiệu
API: PUT /api/v1/admin/brands/{id}
Chức năng: Cập nhật thông tin brand

6. Cập nhật trạng thái
API: PATCH /api/v1/admin/brands/{id}/status
Chức năng: Cập nhật status (ACTIVE/INACTIVE)

7. Xóa mềm brand
API: DELETE /api/v1/admin/brands/{id}/soft-delete
Chức năng: Soft delete brand

8. Khôi phục brand
API: PATCH /api/v1/admin/brands/{id}/restore
Chức năng: Restore brand đã xóa

9. Thao tác hàng loạt
API: PATCH /api/v1/admin/brands/bulk
Chức năng: Bulk delete/restore/update status

10. Lấy brands cho public
API: GET /api/v1/brands
Chức năng: Lấy brands active cho website (không cần auth)
