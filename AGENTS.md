
## Knowledge graph

This repo includes a pre-built code knowledge graph in `graphify-out/`, generated by the graphify tool (graphify is NOT installed on this machine, so do not try to run `graphify` commands).

Before answering questions about the codebase architecture, file relationships, or the impact of a change:

1. Read `graphify-out/GRAPH_REPORT.md` first. It lists the core classes/components (god nodes), how the code is grouped into communities, and file paths.
2. Then open only the source files it points to, instead of scanning the whole project.
3. `graphify-out/graph.json` is large. Do not read it whole. To find how a specific class or component connects to others, grep it for that name and read only the matching entries.
4. Ignore `graphify-out/graph.html` and `graphify-out/cache/`.

The graph is generated from code at a past point in time and may be outdated. Always verify against the actual source files before editing anything.
